Reading
  1. DISPXFER 1: scene 0x18038400 (512x512 RGBA8, tiled) -> 0x18470400 (256x512 RGBA8, linear).
  2. DISPXFER 2: 0x18470400 (linear RGBA8) -> 0x18038400 (256x512 RGB8, tiled). On Android the RGB8
     surface is an RGBA8 texture, so the source alpha (about 0) is copied into it.
  3. DRAW: full-screen quad into the framebuffer at 0x18470400 (256x416 RGBA8, tiled), sampling the
     RGB8 texture with the alpha test "alpha > 7". Alpha is about 0, so every fragment is discarded.
  4. REINTERP-SKIP? / DOWNLOAD: before drawing, the cache refreshes the tiled framebuffer from the
     linear buffer that shares its memory (same stride, so no skip): a GPU readback plus upload,
     every frame. That linear picture shown as tiled data is the horizontal banding.
